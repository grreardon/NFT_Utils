Developed in 2022 - (age 16) 

Discord Bot for per-server configurable Opensea autoposting using Typescript, functionalities include
- extended base discord.js node package core library
- clean OOP class structure 
- automatic cache management system using ioredis built on top of database retrieval
- persistent storage using mongodb
- customizable with collection slug, and the autoposting channel. Stored persistently in mongodob
- Command to see current statistics of the configured item
- automatic posting whenever there is a sale of the configured item
